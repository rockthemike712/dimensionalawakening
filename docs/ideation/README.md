# Ideation round 1 — 25 ideas, 3 critics

Five ideation agents each pitched five ideas through one lens (A spatial
psychedelia, B observer/meta layer, C synesthesia, D dimensional beats,
E moment-to-moment feel), holding the design bible and the full game code.
Three independent critics (player feel, mathematics purist, producer/scope)
scored all 25 on fun · trip · clear · fit (1–10 each, out of 40) without
seeing each other.

- `RANKING.txt` — the tally (mean of the three totals)
- `A-*.md` … `E-*.md` — the 25 pitches in full
- `critic-*.md` — the three critiques, with per-idea scores and kill lists

Top five: D2 The Corner Comes to You · E3 Thin · E2 Octave · B1 Lower the
Lamp · E5 Beads. Recommended build order: Octave → Thin → The Corner.
